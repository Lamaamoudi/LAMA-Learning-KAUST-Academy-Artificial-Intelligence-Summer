🧠 What is Reinforcement Learning?

One-Line Definition Reinforcement Learning is a machine learning paradigm where an agent learns to make decisions by interacting with an environment, receiving rewards as feedback, with the goal of maximizing cumulative reward over time.

The Agent–Environment Loop

Every RL problem follows the same cycle. At each time step $t$:

👁️
Observe state $s_t$
→
🎮
Take action $a_t$
→
🌍
Env transitions $s_{t+1}$
→
🏆
Receive reward $r_t$

This loop repeats until a terminal state is reached (episode ends). The agent's goal is to find a policy that maximizes $\sum_{t=0}^{\infty} \gamma^t r_t$.

⚠️ Why RL is Different In supervised learning, you're told the right answer immediately. In RL, you only get a reward — which might come much later and doesn't tell you which of your past actions caused it. This is the credit assignment problem.

Types of RL Algorithms

The agent does not learn or use a model of the environment. It learns directly from experience.

  • Policy-Based: Learn a policy $\pi(a|s)$ directly (e.g., REINFORCE, PPO, A3C)
  • Value-Based: Learn a value function, derive policy from it (e.g., Q-Learning, DQN, SARSA)
  • Actor-Critic: Combine both — actor (policy) + critic (value)

Most practical algorithms (including those in these lectures) are model-free.

The agent learns or is given a model of the environment: transition dynamics $P(s'|s,a)$ and reward function $R(s,a)$.

  • Learn the model: Fit $P$ and $R$ from data, then plan (e.g., Dyna-Q, World Models)
  • Given the model: Use known dynamics to plan (e.g., AlphaGo, Monte Carlo Tree Search)

Pro: More sample-efficient. Con: Model errors propagate — "model bias".

Why is RL Hard?

A pixel-based game has $256^{84 \times 84 \times 3}$ possible states. A tabular table is impossible. We need function approximation (neural nets).
In chess, reward comes at the end. The agent must figure out which of 50+ moves caused the win or loss — the classic credit assignment problem.
Should the agent stick to the best known action (exploit) or try something new that might be better (explore)? Too much exploration = never converges. Too little = local optima.
Unlike i.i.d. supervised data, RL samples are temporally correlated. As the policy changes, so does the data distribution. This breaks standard SGD assumptions.
In model-free RL, $P(s'|s,a)$ and $R(s,a)$ are unknown. The agent must learn purely from trial and error, which is sample-inefficient.

🗺️ Markov Decision Processes (MDPs)

Formal Definition An MDP is a tuple $\mathcal{M} = (\mathcal{S}, \mathcal{A}, R, P, \gamma)$ where every well-defined RL problem can be cast into this framework.

The Five Components

📍

$\mathcal{S}$ — State Space

All possible situations the agent can be in. Can be discrete (grid cells) or continuous (robot joint angles).

🎮

$\mathcal{A}$ — Action Space

All possible actions. Discrete: {up, down, left, right}. Continuous: torque values.

🏆

$R$ — Reward Function

$R(s,a)$ or $r_t \sim R(\cdot|s_t, a_t)$. Defines what the agent should maximize.

🎲

$P$ — Transition Dynamics

$P(s'|s,a)$ = probability of reaching $s'$ from $s$ after action $a$. Can be stochastic.

⏳

$\gamma$ — Discount Factor

$\gamma \in [0,1)$. Controls how much future rewards matter. $\gamma=0$: myopic. $\gamma \to 1$: far-sighted.

The MDP Interaction Loop

At each time step $t$, the process unfolds as:

  1. Initial state $s_0 \sim p(s_0)$ (sampled from initial distribution)
  2. Agent selects action $a_t \sim \pi(\cdot | s_t)$
  3. Environment samples reward $r_t \sim R(\cdot | s_t, a_t)$
  4. Next state sampled: $s_{t+1} \sim P(\cdot | s_t, a_t)$
  5. Repeat from step 2 until terminal state reached

The Markov Property

Markov Property (Memorylessness) The future is conditionally independent of the past given the present state: $$P(s_{t+1} \mid s_t, a_t, s_{t-1}, a_{t-1}, \ldots) = P(s_{t+1} \mid s_t, a_t)$$ The current state $s_t$ contains all relevant information. You don't need history.

This is what makes MDPs tractable — we only need to track the current state, not the entire trajectory.

Discount Factor $\gamma$ — Intuition

Why discount?
  • Mathematical: Makes infinite-horizon sums converge — $\sum_{t=0}^\infty \gamma^t r_t < \infty$ if $|r_t| \le R_{\max}$ and $\gamma < 1$
  • Economic: A reward now is worth more than the same reward later (time value)
  • Uncertainty: Future rewards are less certain; discounting reflects this
$$G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k} = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \ldots$$ Return $G_t$ — the discounted cumulative reward from time $t$

💎 Policy & Value Functions

What is a Policy?

A policy $\pi$ maps states to actions — it's the agent's decision-making strategy.

$$\pi(s) = a$$Always take the same action in each state

Example: Always go right in state 3. Simple, but inflexible — can't mix strategies.

$$\pi(a|s) = \Pr(a_t = a \mid s_t = s)$$A probability distribution over actions given state

Example: In state 3, go right with prob 0.7, go up with prob 0.3. More expressive — allows randomization which can be optimal in adversarial or partially-observable settings.

The Optimal Policy

Goal of RL Find the policy $\pi^*$ that maximizes expected discounted return: $$\pi^* = \arg\max_{\pi} \; \mathbb{E}\!\left[\sum_{t=0}^{\infty} \gamma^t r_t \;\Big|\; \pi\right]$$

State Value Function $V^\pi(s)$

How good is it to be in state $s$ when following policy $\pi$?

$$V^\pi(s) = \mathbb{E}_\pi\!\left[\sum_{t=0}^{\infty} \gamma^t r_t \;\Big|\; s_0 = s\right]$$ Expected return starting from state $s$, following $\pi$ forever

Action-Value (Q) Function $Q^\pi(s,a)$

How good is it to take action $a$ in state $s$, then follow $\pi$?

$$Q^\pi(s,a) = \mathbb{E}_\pi\!\left[\sum_{t=0}^{\infty} \gamma^t r_t \;\Big|\; s_0 = s,\; a_0 = a\right]$$ Expected return starting from $s$, taking $a$ first, then following $\pi$
🔗 Relationship between V and Q $$V^\pi(s) = \sum_{a} \pi(a|s)\, Q^\pi(s,a)$$ The state value is the expectation of Q-values under the policy's action distribution.

Why Q-Functions are More Useful for Control

Key Insight If you know $Q^*(s,a)$ — the optimal Q-function — you can immediately extract the optimal policy without knowing the environment dynamics: $$\pi^*(s) = \arg\max_{a} Q^*(s,a)$$ This is why Q-learning is so powerful: learn $Q^*$, get $\pi^*$ for free!

Optimal Value Functions

$$V^*(s) = \max_\pi V^\pi(s) = \max_a Q^*(s,a)$$
$$Q^*(s,a) = \max_\pi Q^\pi(s,a)$$

⚙️ Bellman Equations

Core Idea The Bellman equations express value functions recursively — the value of a state equals the immediate reward plus the discounted value of the next state. This recursive structure is the backbone of almost every RL algorithm.

Bellman Expectation Equation for $V^\pi$

$$V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)\Big[R(s,a) + \gamma V^\pi(s')\Big]$$ Value of $s$ = expected (immediate reward + discounted next value)

Bellman Expectation Equation for $Q^\pi$

$$Q^\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) \sum_{a'} \pi(a'|s')\, Q^\pi(s',a')$$ Q-value of $(s,a)$ = reward + discounted expected Q-value of next step under $\pi$

Bellman Optimality Equation for $V^*$

$$V^*(s) = \max_a \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s')\right]$$ Optimal value = take the best action and then follow the optimal policy

Bellman Optimality Equation for $Q^*$

The Most Important Equation in These Lectures $$Q^*(s,a) = R(s,a) + \gamma \, \mathbb{E}_{s' \sim P(\cdot|s,a)}\!\left[\max_{a'} Q^*(s',a')\right]$$ This is what Q-learning and DQN are trying to satisfy.

Recursive Structure — Illustrated

The Bellman equation says: "the value here equals what I get now, plus the best I can do from wherever I end up."

Solving Bellman Equations

If you know $P(s'|s,a)$ and $R(s,a)$, you can iteratively solve the Bellman equations:
  • Policy Evaluation: Compute $V^\pi$ by iterating until convergence
  • Policy Improvement: Update $\pi$ to be greedy w.r.t. current $V^\pi$
  • Value Iteration: Directly compute $V^*$ by iterating the Bellman optimality equation
Not applicable in model-free settings (we don't know $P$ and $R$).
Use sampled transitions $(s, a, r, s')$ to iteratively update Q-estimates: $$Q(s,a) \leftarrow Q(s,a) + \alpha\Big[r + \gamma \max_{a'} Q(s',a') - Q(s,a)\Big]$$ The term in brackets is the Temporal Difference (TD) error — how far the current estimate is from what it "should" be per the Bellman equation.
Use a neural network $Q(s,a;\theta)$ to approximate the Q-function, and minimize the Bellman residual as a loss: $$\mathcal{L}(\theta) = \mathbb{E}\!\left[\Big(r + \gamma \max_{a'} Q(s',a';\theta) - Q(s,a;\theta)\Big)^2\right]$$ More on this in the DQN section!

📊 Q-Learning

What is Q-Learning? Q-Learning (Watkins, 1989) is a model-free, off-policy, value-based RL algorithm that directly learns the optimal action-value function $Q^*(s,a)$ from experience, without needing a model of the environment.

The Q-Learning Update Rule

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \underbrace{\Big[r_t + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t)\Big]}_{\text{TD Error } \delta_t}$$ Where $\alpha \in (0,1]$ is the learning rate
Breaking Down the Update
  • $Q(s_t,a_t)$ — current estimate we're updating
  • $r_t + \gamma \max_{a'} Q(s_{t+1},a')$ — the "target" (what Q should be, per Bellman)
  • TD Error $\delta_t$ — the gap between target and current estimate
  • $\alpha$ — how fast we move toward the target (step size)

ε-Greedy Exploration

How does the agent decide which action to take during learning?

$$a_t = \begin{cases} \text{random action} & \text{with probability } \varepsilon \\ \arg\max_{a} Q(s_t, a) & \text{with probability } 1 - \varepsilon \end{cases}$$
0.30

Q-Learning Algorithm

Algorithm: Q-Learning
1. Initialize $Q(s,a) = 0$ for all $s \in \mathcal{S},\, a \in \mathcal{A}$
2. For each episode:
  3. Initialize $s_0$
  4. For each step $t = 0, 1, 2, \ldots$:
    5. Select $a_t$ via ε-greedy w.r.t. $Q(s_t, \cdot)$
    6. Execute $a_t$, observe $r_t$, $s_{t+1}$
    7. $Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha\big[r_t + \gamma\max_{a'}Q(s_{t+1},a') - Q(s_t,a_t)\big]$
    8. $s_t \leftarrow s_{t+1}$
    9. Until $s_t$ is terminal

Why "Off-Policy"?

Off-Policy Explained Q-Learning is off-policy because it uses $\max_{a'} Q(s',a')$ in the target — this assumes the optimal action will be taken in the future — but the agent might actually be taking a random action (due to ε-greedy). It learns the optimal policy while behaving differently. This means it can reuse old experience!

Convergence Guarantee

Q-Learning converges to $Q^*$ with probability 1 if:

  • All state-action pairs are visited infinitely often (sufficient exploration)
  • The learning rate $\alpha_t$ decays: $\sum_t \alpha_t = \infty$ and $\sum_t \alpha_t^2 < \infty$
  • The MDP is finite (finite $\mathcal{S}$ and $\mathcal{A}$)
  • Rewards are bounded

Limitations of Tabular Q-Learning

📏

Scalability

Stores one value per $(s,a)$ pair. With $10^6$ states × 18 actions = 18M entries. With pixels: impossible.

🐢

Sample Inefficiency

Needs many episodes to visit all states enough times. Real-world environments are expensive to sample.

🧩

No Generalization

Learning $(s,a)$ tells you nothing about similar $(s',a')$. No transfer between states.

⚡

Instability w/ Func. Approx.

When $Q$ is a neural net, correlations + non-stationarity cause divergence. Solution: DQN tricks.

🔬 Deep Q-Network (DQN)

The Problem Q-Learning Can't Solve An Atari game has pixel-based states: $84 \times 84 \times 4$ grayscale frames = 28,224-dimensional input. A tabular Q-table is completely infeasible. We need to generalize across similar states.

Function Approximation

Replace the Q-table with a parametric function — a neural network:

$$Q(s, a;\, \theta) \approx Q^*(s, a)$$ $\theta$ = neural network weights. Same network, different outputs for each action $a$.

The DQN Loss Function

$$\mathcal{L}(\theta) = \mathbb{E}_{(s,a) \sim \mathcal{D}}\!\left[\left(y - Q(s,a;\theta)\right)^2\right]$$ Mean squared error between current Q-estimate and the target $y$
$$y = \mathbb{E}\!\left[r + \gamma \max_{a'} Q(s', a';\, \theta)\right]$$ Bootstrap target (same form as Bellman optimality equation)

DQN Gradient

$$\nabla_\theta \mathcal{L}(\theta) = \mathbb{E}\!\left[\Big(r + \gamma \max_{a'} Q(s',a';\theta) - Q(s,a;\theta)\Big) \nabla_\theta Q(s,a;\theta)\right]$$ Gradient of loss w.r.t. network weights — used to update $\theta$ via SGD
⚠️ Naive DQN Has Two Fatal Problems
  1. Correlated samples: Consecutive transitions $(s_t,a_t,r_t,s_{t+1}), (s_{t+1},\ldots)$ are highly correlated → breaks SGD assumptions → unstable training
  2. Non-stationary targets: Both $Q(s,a;\theta)$ and $\max Q(s',a';\theta)$ use the same network — as we update $\theta$, the target moves too. Like a dog chasing its own tail!

Fix 1: Experience Replay 🎲

Idea Maintain a replay buffer $\mathcal{D}$ storing past transitions $(s_t, a_t, r_t, s_{t+1})$. During training, sample random mini-batches from $\mathcal{D}$ instead of using consecutive transitions.
  • Breaks correlations: Random sampling destroys temporal correlations between consecutive samples
  • Data efficiency: Each transition can be used multiple times for training
  • Stabilizes training: Mini-batch SGD works as intended on approximately i.i.d. data
  • Buffer size: typically 1M transitions (for Atari)
  • FIFO: oldest transitions overwritten when buffer is full
  • Mini-batch size: typically 32 or 64
  • Start training only after buffer has $\geq$ min_buffer_size transitions

Fix 2: Target Network 🎯

Idea Maintain a separate target network $\hat{Q}(s,a;\theta^-)$ with parameters $\theta^-$ that are updated less frequently. The training target becomes: $$y_j = r_j + \gamma \max_{a'} \hat{Q}(s_j', a';\, \theta^-)$$ Every $C$ steps, copy $\theta \rightarrow \theta^-$. Between updates, $\theta^-$ is frozen.
Without target network: every gradient update changes both $Q(s,a;\theta)$ and the target $\max Q(s',a';\theta)$ — they're coupled. The target "moves" with every update, making it impossible to converge.

With target network: the target is fixed for $C$ steps. Now we're fitting $Q(s,a;\theta)$ toward a stable target. More like supervised learning → much more stable.

Full DQN Algorithm (Mnih et al., Nature 2015)

Algorithm: Deep Q-Network (DQN)
1. Initialize replay buffer $\mathcal{D}$ (capacity $N$)
2. Initialize Q-network $Q(s,a;\theta)$ with random weights $\theta$
3. Initialize target network $\hat{Q}$ with $\theta^- \leftarrow \theta$
4. For episode $= 1, M$ do:
  5. Initialize state $s_1$, preprocess $\phi_1 = \phi(s_1)$
  6. For $t = 1, T$ do:
    7. With prob $\varepsilon$: select random $a_t$; else $a_t = \arg\max_a Q(\phi_t, a; \theta)$
    8. Execute $a_t$, observe $r_t$, $s_{t+1}$; set $\phi_{t+1} = \phi(s_{t+1})$
    9. Store $(\phi_t, a_t, r_t, \phi_{t+1})$ in $\mathcal{D}$
    10. Sample random mini-batch $\{(\phi_j, a_j, r_j, \phi_{j+1})\}$ from $\mathcal{D}$
    11. Set $y_j = r_j$ if terminal; else $y_j = r_j + \gamma \max_{a'} \hat{Q}(\phi_{j+1}, a'; \theta^-)$
    12. Gradient descent on $\big(y_j - Q(\phi_j, a_j; \theta)\big)^2$
    13. Every $C$ steps: $\theta^- \leftarrow \theta$

Fix 3: Double DQN (DDQN) 🎯🎯

Problem: Maximization Bias Standard DQN uses $\max_{a'} \hat{Q}(s',a';\theta^-)$ as target. Using $\max$ over noisy Q-estimates is systematically optimistic — it always picks the highest value, which tends to be overestimated noise. This leads to overestimation of Q-values.
Solution: Decouple Selection and Evaluation
  • Selection: Use the current network $\theta$ to pick the best action: $a^* = \arg\max_{a'} Q(s', a'; \theta)$
  • Evaluation: Use the target network $\theta^-$ to evaluate that action
$$y_j = r_j + \gamma \max_{a'} \hat{Q}(s_j', a';\, \theta^-)$$ Same network selects AND evaluates the best action → overestimation bias
$$y_j = r_j + \gamma \, Q\!\left(s_j',\; \underbrace{\arg\max_{a'} Q(s_j', a';\, \theta)}_{\text{select with } \theta};\; \underbrace{\theta^-}_{\text{evaluate with } \theta^-}\right)$$ Current network selects best action; target network evaluates it → unbiased

🔄 SARSA vs. Q-Learning

On-Policy vs. Off-Policy

Off-Policy The agent learns about one policy (the target policy) while behaving according to a different policy (the behavior policy).

In Q-Learning: target policy = greedy $\arg\max Q$; behavior policy = ε-greedy.

Key property: Can reuse old data collected under any policy. Can learn from demonstrations. More aggressive / goal-seeking.
On-Policy The agent learns about the same policy it is currently following. Target and behavior policy are identical.

In SARSA: the update uses the action actually taken next ($a'$), not the greedy best action.

Key property: Learns a safer policy because it accounts for its own exploration behavior.

SARSA — State, Action, Reward, State, Action

SARSA gets its name from the tuple it uses for each update: $(s_t, a_t, r_t, s_{t+1}, a_{t+1})$

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha\Big[r_t + \gamma Q(s_{t+1}, a_{t+1}) - Q(s_t, a_t)\Big]$$ Uses the actual next action $a_{t+1}$ — not $\max$!
Algorithm: SARSA
1. Initialize $Q(s,a) = 0$ for all $s, a$
2. For each episode:
  3. Initialize $s_0$; choose $a_0$ via ε-greedy from $Q(s_0,\cdot)$
  4. For each step $t$:
    5. Execute $a_t$; observe $r_t$, $s_{t+1}$
    6. Choose $a_{t+1}$ via ε-greedy from $Q(s_{t+1},\cdot)$ ← key! choose BEFORE update
    7. $Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha[r_t + \gamma Q(s_{t+1},a_{t+1}) - Q(s_t,a_t)]$
    8. $s_t \leftarrow s_{t+1}$, $a_t \leftarrow a_{t+1}$

The Critical Difference — Side by Side

Q-Learning Target $$r + \gamma \max_{a'} Q(s', a')$$ Always uses the best possible next action. Off-policy, optimistic, aggressive.
SARSA Target $$r + \gamma Q(s', a')$$ Uses the action actually taken next. On-policy, conservative, exploration-aware.

Combined all DQN improvements; modeled full return distribution; risk-aware learning.

Future Directions

🎲

Dueling DQN

Separate network heads for state value $V(s)$ and advantage $A(s,a)$. Better value estimation.

⚡

Prioritized Experience Replay

Sample transitions proportional to their TD error — learn more from surprising experiences.

📊

Distributional RL

Learn the full distribution of returns $Z(s,a)$, not just the mean $Q(s,a)$. Better uncertainty.

🛡️

Safe RL

Add constraints on behavior — don't harm humans, stay within budget. Critical for real-world.
